# Expressa 0.5.0

Mudanças em relação à versão **0.4.4**.

## Breaking changes na linguagem

| Mudança | Como adaptar |
|---|---|
| Removido `para i de … até …`. | Use `para i em 1..=5` para incluir o último valor, ou `1..5` para excluí-lo. |
| Fatias com `..` passam a ter fim **exclusivo**. | Para manter o resultado antigo de `xs[0..2]`, use `xs[0..=2]` ou `xs[0..3]`. Vale para listas e textos. |
| `remova(xs, inicio, fim)` foi removido. | Use `remova(xs, inicio..=fim)` para preservar o intervalo inclusivo antigo. |
| `se_falhar` exige um bloco. | Troque `expr se_falhar 0` por `expr se_falhar { 0 }`. Agora também aceita a mensagem: `expr se_falhar erro { escreva(erro) }`. |
| Removida `tela::casa()`. | Use `posicao_cursor(0, 0, falso)` para voltar ao canto sem apagar e sem forçar o envio imediato da saída. |
| `tela_grafica::evento(g)` mudou de contrato. | A chamada não bloqueia nem aceita tempo de espera. Retorna `:teclas`, `:apertadas`, `:soltas`, `:eventos` e `:sair`; leia os acontecimentos individuais em `ev:eventos`. Controle o ritmo com `durma()` ou com o novo laço gráfico. |
| Documentação `///` precisa ficar imediatamente acima da definição. | Remova linhas em branco ou comentários `//` entre a documentação e a definição. `///` após código na mesma linha é comentário comum. |
| Separadores numéricos `_` são validados. | Use apenas entre dígitos, como `1_000`; formas como `1__0` e `1_` passam a ser erro. |

Os novos nomes nativos `clone`, `falhe`, `garanta` e `infinito` podem conflitar com nomes usados pelo programa; renomeie esses bindings quando necessário.

## Novidades e melhorias

- **Linguagem:** faixas finitas e sem teto; `clone()` para cópia profunda de dados clonáveis; `falhe()` e `garanta()` para gerar erros tratáveis.
- **Gráficos:** laço gráfico com controle de FPS, estado de teclas e eventos ordenados, escala de pixels e melhorias de desempenho.
- **Execução:** compilação para `.lepc`, execução sem o `.lep` original, validação do bytecode e perfil mínimo de compilação.
- **Aula:** painéis podem ser escondidos e restaurados; Argumentos, Painel depurar e Painel inferior preservam a visibilidade entre sessões. Atalhos: Shift+F8, F8 e Ctrl+J; Ctrl+Shift+F12 alterna o conjunto.
- **Correções:** melhorias no editor, armazenamento, sincronização, tratamento de erros, exemplos e build Windows.
