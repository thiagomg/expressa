# Melhorias do editor

A Aula reabre a última pasta do projeto em vez de pedir a pasta toda vez. O último arquivo daquela pasta volta na aba. A barra de status mostra `linha:coluna` do cursor. **Ver → Ir para linha** (Ctrl+G) pede o número e posiciona o cursor.

Essas três coisas eram o que mais atrapalhava o uso no dia a dia: diálogo de pasta a cada F5 da IDE, não saber em que linha se está, e não ter um atalho para pular para a linha de um erro ditado em voz alta.
